Overview

Project Summary

MIDAS Hand is a low-cost, anthropomorphic, tactile dexterous hand designed for robot learning research, hardware teleoperation, manipulation experiments, and sim-to-real development.

This supplement includes local demonstration videos, interactive 3D models, a parts list, assembly instructions, and a software overview.

Total DOF 16
Active DOF 13
3-Axis Taxels 283
Weight ~700 g
BOM ~$3k
Build Time <3 hr
